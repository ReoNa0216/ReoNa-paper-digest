# 秀米排版与账号分流

仅在用户要求把文章带到秀米、测试秀米排版，或询问普通账号与 VIP 差别时读取。本参考描述编辑器中的可选排版路径，不授予公众号同步、公开发布或群发权限。

## 先选路径

说明差别后依据用户要求和页面实际功能选路；不要因为账号有 VIP 就默认使用 HTML 导入。

| 路径 | 做法 | 适用情况与代价 |
|---|---|---|
| 普通编辑器（不使用 HTML 代码导入） | 在新图文或用户指定草稿中录入/粘贴富文本，手动恢复标题、图注和段落，上传并插入图片 | 可测试非 HTML 工作流；耗时较多，源页面 CSS 不会完整继承 |
| VIP HTML 导入 | 页面实际提供“更多 → 导入 HTML 代码”时，上传专用 HTML，预览、修复图片并保存 | 批量导入更快，但秀米会清洗部分样式，仍须逐项验收 |
| 未登录或入口不可用 | 先交付本地阅读页和富文本复制页，登录后按可用入口继续 | 不索要密码、验证码，不反复猜测权限 |

账号类型不明且会影响所选路径时，简短询问账号状态和是否登录。若用户已经指定“普通编辑器、不用 HTML 导入”，可直接走普通路径，无须先确认 VIP。页面权限可能变化，以可见界面为准。“普通编辑器路径已实测”指 005 Tcell to MK 在已登录账号的非 HTML 模式下完成；当时账号显示 VIP，不能据此单独证明每个免费账号都具有完全相同的控件与额度。

## 两条路径的共同准备

1. 以最终复核的 `article.md`、`meta.yaml`、`refs.md` 与本地预览作为唯一稿件来源。提取标题、摘要、正文顺序、节标题、每张图片与对应图注，记录预期数量和位置；不把内部证据台账放进正文。
2. 默认新建独立图文，不覆盖已有草稿。若用户指定已有草稿，先核对标题和身份，再在该范围内操作。
3. 区分图片文件与图注。表格图、导图、论文图都是正文图片；图片上传到“我的图库”后，还须实际插入正文并检查是否加载。不要把本地 `data:image/...`、磁盘路径或未验证的 URL 当作秀米已可用的图片。
4. 仅在用户要求把内容放进秀米时执行页面编辑。保存私有草稿不等于公众号同步、公开发布或群发；超出当前授权范围的操作另行询问。

## 普通编辑器：已验证的非 HTML 路线

这条路线**不打开**“导入 HTML 代码”，也不把 HTML 源码当作正文粘贴。它使用普通编辑器已有的文本、图片和格式控件：

1. 新建图文，填标题和摘要。从 `dist/preview.html` 的富文本复制结果粘贴正文；如果富文本复制不可用，可按源稿顺序录入文本，但保留引用编号、上下标和图注原文。粘贴后先检查整篇是否完整，别假定 CSS 被保留。
2. 在相邻正文段落间设置清晰的空白（空段或秀米的段间距），在桌面/手机预览中确认不会粘连；不要机械地在标题、图片、图注之间叠加多层空白。
3. 逐个设置章节标题的颜色、字号、粗细和对齐；逐条设置图注为较小、弱化的颜色。可使用秀米原生组件；样式值以本篇主题与可读性为准，不把某篇的固定像素或调色板坐标写成通用规则。选区或输入法异常时停止批量操作、检查正文并恢复后再继续。
4. 经网页上传入口把所需图片加入图库，再按文章顺序插入对应图注之前。若同一文件重复使用，确认复用的确是相同图像；不以“图库有图”代替“正文已插图”。
5. 逐段核对首尾、节标题、引文、图表顺序、图片加载、图注内容与样式、空白节奏。保存草稿后确认稿件标题和草稿 URL/ID；若保存反馈不明确，如实标注而不是推断成功。

005 Tcell to MK 的一次实操使用了此路径：正文与段落空白、7 个编号标题、17 张插图及对应的 17 条图注在编辑器中完成；图注最终核对为 16px 灰色。这个数字只是该测试稿的验收记录，下一篇按其自身素材清单核对，不硬套 17 张或固定配色。普通路径可以保留内容结构和手工设置的样式，但不代表原 HTML/CSS 完整同步。

## VIP：可选的 HTML 导入路线

仅在用户选择且已登录页面显示该入口时执行。先保留原始 `dist/article.html`，另生成 `dist/xiumi-import.html` 等专用副本，使用简单的内联 CSS 表示正文、标题、图注、段落间距；不要依赖脚本、外部样式表、伪元素或复杂布局。

1. 在“更多 → 导入 HTML 代码”选择专用文件，先看导入预览，再提交到新图文或用户指定草稿。
2. 检查标题颜色/对齐/边框、图注、段落间距、图片数量和实际加载。秀米可能清洗不支持的 CSS，并清除 `data:image/...` 图片源；必要时从该账号图库恢复图片或改用原生组件，不能猜测图片地址。
3. 导入后重新检查编辑态和预览态；预览保留样式不等于保存后永久保留。保存私有草稿后记录 URL/ID 与尚未修复的问题。

普通账号不应被承诺能使用该 HTML 入口。Word、Markdown 或公众号文章导入仅在页面实际提供并且用户选择时作为额外替代，不把它们误称为“普通编辑器直接 HTML 导入”。

## 交付记录与失败边界

交付时报告所选路径、是否实际保存、标题/图注样式、段落空白、图片插入并加载的数量/预期数量，以及残留问题。程序性结构检查、秀米预览检查与公众号后台粘贴检查分开记载。登录中断、文件选择器失败或图片无法恢复时，保留本地源和具体阻塞点，不声称已完成。

秀米公开的[图文同步接口文档 2.0](https://ent.xiumi.us/)描述平台申请同步 app、绑定用户并接收 HTML/图片的服务端对接；它不是普通编辑器操作，也不等于 VIP HTML 导入。没有独立接口配置与用户要求时，不声称已实现 API 接入。
